\begin{frame}{One CWL workflow: pgr-tk extraction, Immuannot typing, pgr-tk and pggb graphs}
  \begin{itemize}
    \item 754 haplotypes: 610 assembled (APR, HPRC release 2, JaSaPaGe) and 144 read from pangenome graphs (K-PanRef, CPC), plus GRCh38 and CHM13
    \item MHC (GRCh38 chr6:28.5--33.5 Mb, 100 kb flank) pulled from each haplotype with pgr-tk \texttt{pgr-query}, about 30 s per genome
    \item Immuannot (IPD-IMGT/HLA 3.55) gives gene structure and full-resolution allele calls per haplotype
    \item Per gene (19 genes): sequences cut at the Immuannot coordinates, pgr-tk principal-bundle plots, pggb graphs rendered with odgi
    \item Whole MHC and the class II block (DRA to DMA): pgr-tk bundle decomposition, dendrograms, bundle graphs
    \item Second typing method (FuFiHLA) on every individual; T1K on 1000 Genomes Illumina reads
    \item Runs on the NIG supercomputer without containers (Toil, \texttt{--no-container}); repo \texttt{github.com/leechuck/pangenome-bh26}
  \end{itemize}
\end{frame}

\begin{frame}{Nine cohorts from five projects; HPRC is split by population and two cohorts exist only as graphs}
  \begin{itemize}
    \item Assemblies
    \begin{itemize}
      \item APR, UAE Arab Pangenome Reference: 106 haplotypes
      \item JaSaPaGe: Saudi (ksa*) 18, Japanese (1000G JPT) 20
      \item HPRC release 2, split with the 1000G population labels and the HPRC sample table: Japanese (JPT) 32, Ashkenazi Jewish 2 (HG002 is the only Jewish individual), other East Asian (CHB, CHS, CDX, KHV, HG005) 70, rest 360
    \end{itemize}
    \item Pangenome graphs without released assembly files
    \begin{itemize}
      \item K-PanRef, Korean pangenome (Minigraph-Cactus): 14 individuals, 28 haplotypes
      \item CPC Phase 1, Chinese Pangenome Consortium (Minigraph-Cactus): 58 individuals, 116 haplotypes; its 3 HPRC samples are not added twice
    \end{itemize}
    \item Five JPT individuals were assembled by both HPRC and JaSaPaGe and are kept as separate haplotypes
  \end{itemize}
\end{frame}

\begin{frame}{How: population labels and MHC haplotypes from the Korean and Chinese graphs}
  \begin{itemize}
    \item HPRC split: population code per sample from the 1000G high-coverage sequence indexes (\texttt{POPULATION} column), HPRC release 2 sample metadata for non-1000G samples (HG002 Ashkenazi, HG005 Han Chinese); table \texttt{data/hprc\_r2\_populations.tsv}, used by \texttt{make\_inputs.py --populations}
    \item K-PanRef (\texttt{KPanRef.gbz}): all haplotype paths of a sample with \texttt{vg paths -F}; only KOREF1 has chromosome-named contigs, so path segments are kept when a minimap2 asm20 alignment to the GRCh38 MHC has $\ge$ 50 kb matching bases and MAPQ $\ge$ 20 (\texttt{nig/kpanref\_mhc.sbatch})
    \item CPC: the odgi file holds only reference paths, so haplotype walks (W lines) are read from the GFA; reference MHC nodes from \texttt{odgi extract} of CHM13v2 chr6:28--34 Mb, each walk kept from its first to last MHC node, segment sequences from a second GFA pass, same alignment filter (\texttt{nig/cpc\_mhc.sbatch})
    \item Both then enter the same extraction and Immuannot steps as the assemblies (\texttt{nig/add\_graph\_cohorts.sbatch})
  \end{itemize}
\end{frame}

\begin{frame}{How: MHC extraction with pgr-tk (workflow steps prepare\_reference, extract\_pgrtk)}
  \begin{itemize}
    \item Query: GRCh38 chr6:28,510,120--33,480,577 plus 100 kb flank, cut from the PanSN GRCh38 fasta with samtools faidx
    \item Per haplotype: \texttt{pgr-query --fastx-file -w 80 -k 56 -r 4 --min-span 64 --merge-range-tol 100000} (SHIMMER index of the input in memory, 8 threads, about 30 s and 9 GB per 3 Gb haplotype)
    \item Hits under 20 kb or under 20 anchors dropped; minus-strand hits reverse-complemented; records renamed \texttt{sample\#hap\#contig:start-end}; coverage = query span covered by kept hits (\texttt{scripts/pgr\_query\_rename.py})
    \item Samples present in two projects get a \texttt{.cohort} suffix; figure: \texttt{analysis/fig2\_extraction.py}
    \item The five JPT individuals assembled twice: 59 of 61 full-resolution gene calls agree between their HPRC and JaSaPaGe assemblies; the two exceptions differ only in an intron
  \end{itemize}
\end{frame}

\begin{frame}{How: allele calling and aggregation (steps immuannot, aggregate)}
  \begin{itemize}
    \item Immuannot v3 (\texttt{immuannot.sh -c <mhc.fa> -r Data-2024Feb02 --diff 0.03}, 4 threads) on each extracted MHC: IPD-IMGT/HLA 3.55 genomic sequences, IPD-KIR 2.13, RefSeq C4; 754 runs
    \item Allele = Immuannot \texttt{consensus} field of the transcript row; \texttt{:new} marks a full-length sequence absent from the database; novel coding vs noncoding from \texttt{cds\_distance}
    \item \texttt{scripts/aggregate\_immuannot.py}: hla\_calls.tsv (one row per gene copy), haplotype x gene matrix, copy numbers (C4A/B long/short, DRB3/4/5 presence), per-cohort two-field frequencies and plots
    \item Heat maps: top 6 two-field alleles per cohort, frequency = fraction of haplotypes; figure: \texttt{analysis/fig5\_population.py}, cohort order and colors in \texttt{analysis/cohorts.py}
  \end{itemize}
\end{frame}

\begin{frame}{How: novel-allele support (scripts/novel\_alleles.py, analysis/fig4)}
  \begin{itemize}
    \item Immuannot \texttt{cds\_mut} gives the closest allele and the CDS-relative differences (assembly base first); converted to contig coordinates through the CDS rows, strand-aware
    \item Independent-assembly support (610-haplotype run): the 31-mer centred on each variant searched in the same gene cut from all other haplotypes; carriers counted, including the other haplotype of the same individual
    \item Read support (HPRC individuals only): 1000G Illumina reads of the same person realigned to the assembled contig (minimap2 -ax sr), samtools mpileup $\pm$40 bp around the codon
    \item Newer database check: coding sequence of each assembled gene aligned with minimap2 -x splice:hq to all coding alleles of IPD-IMGT/HLA 3.65 (T1K index); HG02717: exact over exons 2--6 to DQB1*02:180:02; NA20346: closest DPA1*03:02:02, 1 substitution
    \item Indel-only ``new'' alleles (ksa004 HLA-A, HG03516 DPA1) flagged as likely HiFi homopolymer errors
  \end{itemize}
\end{frame}

\begin{frame}{How: three typing methods and two truth sets (analysis/typing\_concordance.py)}
  \begin{itemize}
    \item FuFiHLA 0.2.4 (Bioinformatics 2026, btag231; long-read typing of A, B, C, DRB1, DQA1, DQB1; IPD-IMGT/HLA 3.65): no public long reads for most cohorts, so both assembled MHC haplotypes of an individual are tiled into error-free 15 kb pseudo-reads every 1.5 kb and typed together (\texttt{nig/fufihla\_assemblies.sbatch}); checked on HG002, 12 of 12 alleles
    \item FuFiHLA artefact test: each reconstructed allele aligned to the individual's assembled gene copies; a consensus absent from the assembly is flagged
    \item T1K (Genome Research 2023) on all reads aligned to the MHC, chr6 alternative haplotypes and HLA contigs, extracted from the 2,504 1000G high-coverage CRAMs on the NIG shared data area; alleles with quality 0 ignored (\texttt{nig/kg\_mhc\_reads.sbatch})
    \item Comparison: unordered allele pairs truncated to 1--4 fields; published ambiguity lists count as a match if any member matches; truth sets in \texttt{1000g\_ground\_truth/} (repository)
  \end{itemize}
\end{frame}

\begin{frame}{How: class II bundle decomposition with pgr-tk (scripts/extract\_span.py, tools/pgr\_pbundle.cwl, analysis/classII\_bundles.py)}
  \begin{itemize}
    \item Span: from HLA-DRA to HLA-DMA (outermost Immuannot coordinates, 20 kb flank) cut from every MHC haplotype in DRA orientation with samtools faidx; 753 sequences
    \item \texttt{pgr-pbundle-decomp -w 48 -k 56 -r 2 --min-span 8 --bundle-length-cutoff 500 --bundle-merge-distance 2000}: 890 principal bundles; \texttt{pgr-pbundle-bed2dist} for distances and dendrogram, \texttt{bed2sorted} for bundle-presence vectors, \texttt{bed2svg} for the bundle plot
    \item PCA: haplotype x bundle presence matrix, centered, SVD; colors from Immuannot (secondary DRB gene) and cohort labels
    \item Dendrogram: Newick from bed2dist, leaves mapped to haplotypes, color strips from the allele calls and cohorts; cluster purity at 10--80 clusters in \texttt{classII\_cluster\_purity.tsv}
    \item Bundle graph: nodes = bundles from the bed file, edges = consecutive bundles along each haplotype weighted by haplotype count, Kamada-Kawai layout
  \end{itemize}
\end{frame}

\begin{frame}{How: per-gene sequence sets and graphs (steps gene\_extract, gene\_bundle, gene\_graph, gene\_viz, gene\_draw)}
  \begin{itemize}
    \item Gene sequences: every annotated copy cut at its Immuannot coordinates with 2 kb flank, gene orientation, named \texttt{sample\#hap\#GENE} (\texttt{scripts/extract\_genes.py})
    \item pgr-tk per gene: \texttt{pgr-pbundle-decomp -w 48 -k 56 -r 2 --bundle-length-cutoff 200 --bundle-merge-distance 1000}, then bed2dist / bed2sorted / bed2svg
    \item pggb 0.7.4 per gene: \texttt{-p 90 -s 2000 -n <sequences> -P asm20}; odgi viz (1D, rows = haplotypes) and odgi layout + draw (2D)
    \item Whole MHC: pgr-pbundle-decomp w=80, k=56, r=6, min\_span 28 on the MHC fasta of all haplotypes
    \item Runtime of the 754-haplotype aggregation, gene cuts, bundles and graphs: 4.3 h on 16 cores (Toil single machine)
  \end{itemize}
\end{frame}

  \begin{itemize}

\begin{frame}{Take-home}
  \begin{itemize}
    \item Assembly-based HLA typing across five pangenome projects reproduces known population frequencies and reveals data problems (duplicated haplotype, homozygous individuals) that short reads alone would not
    \item Pangenome graphs without released assemblies (K-PanRef, CPC) still yield complete MHC haplotypes and allele calls
    \item 57--79\% of DRB1 gene copies have no full-length match in IPD-IMGT/HLA 3.55; ``novel'' calls must be rechecked against the newest release (HG02717 DQB1 was named in 3.56)
    \item Two assembly-based typing methods agree with truth sets at 2-field resolution; FuFiHLA on assembly pseudo-reads needs a homozygosity check
    \item Open: aligning the 1000G MHC reads to the whole-MHC graph; APR and JaSaPaGe raw reads for novel-allele validation; KIR and IGH with the same workflow
    \item Workflow, scripts, figures and tables: \texttt{github.com/leechuck/pangenome-bh26} (\texttt{hla/})
  \end{itemize}
\end{frame}
